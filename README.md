# 🚀 React Paste App

A modern and responsive paste management application built using React, Vite, and Redux.  
This app allows users to create, manage, search, update, and share text snippets easily with a clean dark-themed UI.

---

# ✨ Features

- 📝 Create and save text snippets (pastes)
- ✏️ Edit existing pastes
- 👀 View saved pastes
- 🗑️ Delete unwanted pastes
- 📋 Copy paste content instantly
- 🔍 Search through saved pastes
- 📤 Share pastes via social platforms
- 💾 Local storage support
- 🌙 Modern dark mode UI
- 📱 Fully responsive design

# 📚 Project Functionality

This project is designed to simplify note and snippet management.  
Users can quickly create text snippets and store them locally without requiring authentication or a backend.

The application provides:
- Fast performance using Vite
- Smooth state management with Redux
- Responsive UI for desktop and mobile devices
- Instant searching and filtering experience
